<p align="center"><a href="README.md">English</a> | <b>Русский</b></p>

qrec записывает прямоугольную область экрана или экран целиком в файл MP4: видео H.264, закодированное видеокартой, звук, который воспроизводит компьютер, в формате AAC, и указатель мыши. В окне находятся немногочисленные настройки, а глобальная горячая клавиша начинает и останавливает запись из любого окна.

## Возможности

- **Область или экран**: область рисуется мышью поверх затемнённого экрана, свободно или в пропорциях 16:9 или 1:1, и запоминается; во время записи её обозначает красная рамка.
- **Аппаратное кодирование**: H.264 кодером видеокарты NVIDIA, Intel или AMD через Media Foundation, с программным кодером Microsoft в качестве запасного; кадры попадают с экрана в кодер, не покидая видеокарту.
- **Звук компьютера без «Стерео микшера»**: всё воспроизводимое захватывается через WASAPI loopback и записывается в AAC; виртуальный кабель или драйвер не нужны.
- **Указатель** рисуется в записи, включая инвертированный текстовый курсор.
- **Три настройки**: 30 или 60 кадров в секунду, качество в три ступени (битрейт зависит от размера области), запись звука и указателя.
- **Горячая клавиша**: по умолчанию `Ctrl+Alt+R`, меняется в окне нажатием другого сочетания или убирается.
- **Значок в области уведомлений**: красный во время записи, с записанным временем во всплывающей подсказке; его меню начинает и останавливает запись и позволяет оставить программу только в области уведомлений, без кнопки на панели задач, сделать так, чтобы крестик окна скрывал её туда, или убирать окно в начале записи.
- **В записи нет самого qrec**: его окна исключаются из захвата.
- **Русский и английский**: язык интерфейса следует языку Windows или выбирается в окне «О программе».
- **Один файл**: без FFmpeg, без среды выполнения, без обращений к сети; исполняемый файл занимает около 7 МБ.

## Установка

Установщик и переносной архив публикуются на странице [Releases](https://github.com/Fan4Metal/qrec/releases).

Установщик `qrec_<версия>_Setup.exe` не требует прав администратора: программа помещается в `%LOCALAPPDATA%\Programs\qrec`. Установленная программа хранит настройки в `%APPDATA%\qrec`.

Переносной архив `qrec_<версия>_portable.zip` содержит программу в папке `qrec` и работает без установки. В нём также лежит пустой файл `app.ron`: пока он находится рядом с `qrec.exe`, настройки хранятся в той же папке, и программу можно носить на съёмном диске (папка должна быть доступна для записи); без него настройки хранятся в `%APPDATA%\qrec`, как у установленной программы.

Требования: Windows 10 версии 2004 или новее, 64-разрядная. На более ранних сборках Windows 10 программа работает, но звук захватывается с устройства вывода по умолчанию, а не через loopback процесса (см. [Звук](#звук)), и окна qrec могут попасть в запись.

## Использование

| Настройка | Значение |
|---|---|
| Экран | Монитор для записи, если их несколько. Область принадлежит одному монитору. |
| Пропорции | **Свободные**, **16:9** или **1:1**: форма области, рисуемой мышью. Область 16:9 меняется с шагом 2 пикселя, а её высота округляется до чётного числа, которого требует H.264, поэтому она отличается от 16:9 не больше чем на пиксель и точна там, где соотношение это допускает (1280×720, 1920×1080); область 1:1 квадратная. Угол, с которого начато выделение, остаётся на месте, а область не выходит за край монитора. Уже выбранная область принимает новые пропорции вокруг своего центра. |
| Область | **Выделить…** скрывает окно и затемняет экран; область рисуется левой кнопкой мыши, `Esc` или правая кнопка отменяют выделение. **Весь экран** записывает монитор целиком. Текущий из двух вариантов подсвечен. Область запоминается между запусками. |
| Частота кадров | 30 или 60 кадров в секунду. Неподвижный экран ничего не стоит: повторяется последнее изображение. |
| Качество | Низкое, среднее или высокое: примерно 0,05, 0,1 или 0,2 бита на пиксель и кадр. Для 1920×1080 при 30 кадрах в секунду это около 3, 6 или 12 Мбит/с. Рядом с кнопками показывается наибольший объём записи выбранной области, в Мбит/с и в мегабайтах за минуту вместе со звуком; неподвижный экран занимает меньше. |
| Записывать | **Звук системы**: то, что воспроизводит компьютер. **Указатель**: указатель мыши. |
| Папка | Куда сохраняются файлы; по умолчанию `Видео`. **Открыть** показывает папку в Проводнике. |
| Клавиша | Начинает и останавливает запись из любого окна. Щелчок по кнопке **Изменить**, затем клавиша с `Ctrl`, `Alt` или `Win` либо функциональная клавиша задают другое сочетание; `Esc` или **Отмена** оставляют текущее; крестик рядом с **Изменить** убирает клавишу. Сочетание, занятое другой программой, помечается как недоступное. |

**Запись** начинает запись; пока она идёт, кнопка показывает записанное время и по щелчку останавливает запись. Число пропущенных кадров, если компьютер не успевал, показывается ниже. Во время записи область окружена красной рамкой. Файл называется по дате и времени, `qrec_2026-10-08_16-45-12.mp4`, а после записи его имя появляется в окне в виде ссылки, которая показывает файл в Проводнике.

Область обрезается по монитору, на котором она начата, её стороны делаются чётными (как требует H.264), и каждая сторона составляет не менее 64 пикселей. Если область оказалась вне монитора, например после перестановки экранов, записывается весь экран.

Значок qrec в области уведомлений становится красным во время записи, а его подсказка показывает записанное время. Щелчок по значку выводит окно на передний план; его меню (правая кнопка) начинает или останавливает запись, показывает окно, открывает **О программе** или закрывает программу. **Не показывать на панели задач** в том же меню убирает кнопку окна с панели задач (и из `Alt+Tab`): тогда кнопка сворачивания скрывает окно, а значок возвращает его. **Сворачивать в трей при закрытии** заставляет крестик в углу окна скрывать окно, а не закрывать программу; `Alt+F4` и пункт **Выход** по-прежнему её закрывают. **Сворачивать при начале записи** сворачивает окно, когда запись начинается, каким бы способом она ни была начата (а если окна нет на панели задач, скрывает его). Выборы запоминаются. Windows 10 помещает новый значок среди скрытых, за стрелкой; оттуда его можно перетащить на панель задач.

Кнопка **i** в строке заголовка окна (или пункт **О программе** в меню значка) показывает версию, автора, сайт проекта и лицензию, место хранения настроек и язык интерфейса: как в Windows, английский или русский; выбор применяется сразу и запоминается.

Закрытие окна во время записи сначала завершает файл.

## Звук

Звук захватывается через *loopback процесса*, доступный в Windows 10 версии 2004 и новее: аудиодвижок отдаёт всё, что воспроизводят другие программы, в 16-битном стерео на 48 кГц, независимо от устройства вывода и без «Стерео микшера» или виртуального кабеля. Собственные звуки qrec, если бы они были, в запись не попадают. Программы, воспроизводящие звук в монопольном режиме WASAPI, минуют аудиодвижок и не захватываются.

На более ранних сборках Windows 10 вместо этого для loopback-захвата открывается устройство вывода по умолчанию, и записывается то, что воспроизводится через него.

Звук и видео используют одни часы, счётчик производительности Windows: пакет звука помещается на то время, когда он был записан, промежутки заполняются тишиной, а кадры видео получают метки через равные интервалы тех же часов, поэтому дорожки не расходятся.

## Ограничения

- Экраны с включённым HDR пока не поддерживаются: захват отдаёт кадры в 16-битном формате с плавающей запятой, которые программа не преобразует. О таком экране сообщается при начале записи.
- Повёрнутые экраны захватываются в исходной ориентации.
- Содержимое, которое Windows защищает от захвата (некоторые видеоплееры, DRM), выглядит чёрным, как при любом захвате экрана.
- Одна область на одном мониторе; нет паузы, микрофона и веб-камеры.

## Командная строка

```
qrec.exe --record СЕКУНДЫ [--region X,Y,W,H] [--monitor N] [--fps N] [--quality low|medium|high] [--no-audio] [--no-cursor] [--out ФАЙЛ]
```

Записывает без окна заданное число секунд, из консоли: `--region` задаётся на виртуальном экране (в физических пикселях), `--monitor` считается с 1, основной экран первый, а по умолчанию записывается весь основной экран при 30 кадрах в секунду и среднем качестве, со звуком и указателем, в файл `qrec_<дата>_<время>.mp4` в текущей папке.

## Сборка

Требования: Windows 10 или новее, стабильный Rust с набором инструментов MSVC и Visual Studio 2022 Build Tools.

```
cargo build --release    # target\release\qrec.exe
cargo test
```

Окно отрисовывается egui/eframe через OpenGL (glow). Захват экрана, преобразование цвета, кодирование, мультиплексирование и захват звука выполняются средствами самой Windows: Desktop Duplication, видеопроцессор Direct3D 11, Media Foundation и WASAPI через крейт `windows`. Исполняемый файл собирается со встроенной библиотекой времени выполнения C (`.cargo/config.toml`, `crt-static`), так что qrec не требует ничего, кроме самой Windows. Переменная окружения `QREC_TRACE=1` включает вывод хода записи в stderr (у отладочной сборки есть консоль; релизная сборка выводит в консоль, из которой запущена).

## Установщик и выпуск

Скрипт выпуска собирает исполняемый файл, установщик и переносной архив (требуется Inno Setup 6):

```
python tools/make_release.py              # тесты, сборка, установщик, архив
python tools/make_release.py --no-tests   # то же без cargo test
python tools/make_release.py --install    # затем тихая установка поверх установленной копии
```

Файлы записываются в папку `dist`, версия берётся из `Cargo.toml`. Скрипт сначала закрывает `qrec.exe`, запущенный из `target\release`. Сценарий установщика находится в `tools/setup.iss`; значок установщика записывает команда `qrec.exe --export-icon <файл.ico>`.

Выпуски на GitHub собирает workflow **Release** (`.github/workflows/release.yml`). После того как версия в `Cargo.toml` обновлена и закоммичена, отправка соответствующего тега публикует выпуск с установщиком и переносным архивом:

```
git tag v0.1.0
git push origin v0.1.0
```

Ручной запуск workflow (Actions → Release → Run workflow) только собирает файлы и прикрепляет их к запуску, не создавая выпуск.

## Используемые проекты

qrec построен на следующих проектах с открытым исходным кодом:

- [egui / eframe](https://github.com/emilk/egui): интерфейс и окно программы;
- [windows-rs](https://github.com/microsoft/windows-rs): API Windows из Rust;
- [Inno Setup](https://jrsoftware.org/isinfo.php): установщик.
